# Google Pay UI Clone (React Learning Project)

This project is a visually accurate clone of the **Google Pay** mobile application interface, built entirely with React.

I designed and developed this project when I first started learning React. The primary goal was to understand modern front-end concepts by breaking down a complex, real-world application into smaller, manageable pieces. 

## Key Learnings & Features

- **Component-Based Architecture**: I focused heavily on building **reusable components** (such as the Action Grid icons, Biller circles, and Promo banners) to keep the codebase DRY (Don't Repeat Yourself) and maintainable.
- **Responsive & Mobile-First Design**: Developed a custom `MobileFrame` wrapper that simulates a mobile device on desktop browsers, ensuring the application looks exactly like the native Android/iOS app.
- **Routing & State**: Used `react-router-dom` to handle navigation between different screens (like Mobile Recharge, Bank Transfer, Bills, etc.).
- **Modern CSS Styling**: Implemented intricate UI elements like floating cards, curved gradient headers, and line-clamp truncations using custom CSS and Bootstrap classes.
- **Dynamic Data Rendering**: Mapped over data arrays to dynamically render lists of contacts (in the People section) and billers, simulating real data fetching scenarios.

## Getting Started

In the project directory, you can run:

### `npm install`
### `npm start`

Runs the app in the development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
The page will reload when you make changes.
